# CTD - Nexus Mod Descriptions

## Skyrim Special Edition (SKSE64)

### Short Description
Crash reporter that captures stack traces, load order, and crash context. Helps mod authors diagnose issues by detecting patterns across users.

### Long Description
[size=5][b]CTD - Crash To Desktop Reporter[/b][/size]

[b]What is CTD?[/b]
CTD captures crash context and makes it easy to share with mod creators. When your game crashes, CTD automatically collects:

[list]
[*]Stack traces with module offsets for debugging
[*]Your load order at crash time
[*]System information relevant to the crash
[/list]

[b]Why use CTD?[/b]
[list]
[*][b]Pattern Detection[/b] - CTD identifies when multiple users experience the same crash, helping pinpoint the cause
[*][b]Easy Sharing[/b] - Generate a link to share your crash report with mod authors or support channels
[*][b]Privacy First[/b] - Anonymous by default, no account required, no personal information collected
[/list]

[b]For Mod Authors[/b]
Subscribe to crashes mentioning your mods at [url=https://ctd.ezmode.games]ctd.ezmode.games[/url]:
[list]
[*]See crash reports where your mod appears in the load order
[*]Detect patterns like "crashes with ENB + specific mod combinations"
[*]Communicate fixes directly to affected users
[*]Export crash data for analysis
[/list]

[b]Requirements[/b]
[list]
[*]SKSE64
[*]Address Library for SKSE Plugins
[/list]

[b]Installation[/b]
Install with your mod manager or extract to your Skyrim SE Data folder.

[b]Privacy[/b]
[list]
[*]No account required
[*]Only mod names collected (no file paths)
[*]No personally identifiable information
[*]Anonymous reports retained 90 days
[/list]

[b]Open Source[/b]
CTD is AGPL-3.0 licensed. Source code: [url=https://github.com/ezmode-games/ctd]github.com/ezmode-games/ctd[/url]
